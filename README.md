# Dad Joke Showdown — The Sketchy Pen

One original dad joke, written to be told out loud at the dinner table: a father,
his son, a pen, and a conclusion drawn a little too sketchily.

## The joke

> My son asked why I carry a pen everywhere. I said, 'In case I need to draw a conclusion — and mine are always sketchy.'

## How it works

`main.py` (Python 3.13, standard library only, deterministic, no network) writes the
single dad joke to `/output/entry.txt`.
